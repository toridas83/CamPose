# CamPose 프로젝트 개발 현황

## 1. 프로젝트 개요

CamPose는 PC 웹캠을 이용해 사용자의 자세를 실시간으로 분석하고, 나쁜 자세가 일정 시간 지속되면 피드백을 제공하는 오프라인 데스크톱 프로그램이다.

## 2. 주요 기술

- Python 3.11
- CustomTkinter
- MediaPipe Pose Landmarker
- OpenCV
- Pillow
- Pystray
- JSON 기반 로컬 데이터 저장

## 3. 구현 기능

### 자세 분석

- MediaPipe를 이용한 33개 신체 관절점 추출
- 개인 기준 자세와 현재 자세 비교
- 최근 프레임 중앙값을 이용한 흔들림 보정
- 자세별 1~3단계 심각도 판정
- 상체와 하체가 보이는 경우 다리 자세 분석

### 감지 자세

- 거북목
- 고개 숙임
- 고개 기울임
- 어깨 비대칭
- 어깨 으쓱
- 몸통 전방 기울임
- 몸통 측면 기울임
- 몸통 비틀림
- 화면에 가까운 자세
- 한쪽 또는 양쪽 다리 올림
- 다리 꼬기

### 기준 자세 설정

- 한 장의 사진이 아닌 10초 동안의 다중 프레임 사용
- 특징값의 중앙값과 흔들림 정도 저장
- 사용자별 체형과 카메라 위치 차이 보정
- 촬영 완료 후 자동으로 메인 화면 복귀

### 알림

- 현재 모니터 우측 하단 팝업
- 화면 가장자리 점멸 효과
- 팝업과 테두리 동시 사용
- 시스템 경고음
- 화면 알림과 경고음 개별 설정
- 자세 단계별 허용시간 설정

나쁜 자세가 잠시 해제되더라도 회복 판정 시간을 채우지 못하면 같은 자세 상태로 유지한다. 회복 시간이 지난 후 같은 나쁜 자세가 재발하면 알림 시간을 0초부터 다시 계산한다.

### 카메라

- 현재 PC에 등록된 카메라 장치명 자동 검색
- 물리 카메라와 가상 카메라 구분
- 설정 저장 시 선택한 카메라 즉시 재연결
- 하나의 카메라 프레임을 분석 화면과 개발용 캠이 공유

### 기록

- 측정 시간
- 좋은 자세 비율
- 경고 횟수
- 자세별 누적시간과 최고 단계
- 세션별 상세 통계
- 자세별 지속시간 그래프
- 개별 기록 및 전체 기록 삭제

현재 데이터는 로컬 JSON 파일로 저장되며, SQLite 전환은 추후 과제로 남아 있다.

### 백그라운드 실행

- 창을 닫을 때 트레이 숨김 또는 완전 종료 선택
- 트레이에서 대시보드 다시 열기
- 백그라운드에서도 자세 분석과 알림 유지
- 터미널 `Ctrl+C` 안전 종료 지원

## 4. 개인정보 처리

- 카메라 영상과 이미지는 저장하지 않음
- 자세 특징값과 측정 결과만 로컬에 저장
- 외부 서버나 인터넷 통신 없이 실행 가능

## 5. 남은 개발 과제

- JSON 데이터를 SQLite로 이전
- 자세 판정 임계값 실사용자 검증
- 둥근 어깨와 하체 자세 정확도 개선
- 장시간 움직임 부족 및 휴식 알림 구현
- EXE 패키징과 설치 프로그램 제작
- Windows 로그인 시 자동 실행 옵션
- 사용자별 통계 및 장기 리포트 강화
