# CamPose 개발용 MVP

정면 웹캠과 MediaPipe Pose Landmarker를 사용해 개인 기준 자세 대비 변화를 분석하는
로컬 CustomTkinter 애플리케이션입니다. 영상/이미지는 저장하지 않고 설정, 기준 자세의
수치, 측정 요약만 `data/` 폴더의 JSON 파일로 저장합니다.

## 실행

```powershell
conda activate test
cd D:\05_opensource_contest\CamPose-main
python main.py
```

모델 파일 `pose_landmarker_lite.task`는 프로젝트 폴더 또는 그 상위 폴더에 있어야 합니다.

## 처음 사용할 때

1. `기준 자세 설정`에서 정면을 보고 10초간 기준 자세를 촬영합니다.
2. `측정 시작`을 누릅니다.
3. `개발용 캠 열기`에서 스켈레톤, 자세 종류/단계/시간, 특징값을 확인합니다.
4. `측정 종료 및 기록 저장`을 누른 뒤 `기록` 화면을 확인합니다.

## 추가 기능

- 기준 자세와 개발용 캠은 별도 창이 아니라 앱 내부 페이지에서 열립니다.
- `기록 > 상세 보기`에서 세션별 요약과 자세별 지속시간 그래프를 확인할 수 있습니다.
- 기록은 개별 삭제하거나 전체 삭제할 수 있습니다.
- 설정의 빠른 프리셋은 아래 세부 옵션에 즉시 반영됩니다.
- `설정 > 화면 알림 방식`에서 앱 자체 우측 하단 팝업, 화면 테두리 강조 또는 두 효과의 조합을 선택할 수 있습니다.
- `화면 알림 테스트` 버튼으로 다른 프로그램 위에서도 효과가 보이는지 바로 확인할 수 있습니다.
- 카메라 목록은 Windows DirectShow 장치명으로 자동 검색됩니다. 카메라 변경은 앱 재실행 후 적용됩니다.
- 창의 X 버튼을 누르면 트레이로 숨길지 완전히 종료할지 선택할 수 있습니다. 사이드바의 `백그라운드로 숨기기`와 `앱 완전히 종료` 버튼도 사용할 수 있습니다.
- 카메라를 변경하고 설정을 저장하면 앱을 재실행하지 않아도 선택한 장치를 즉시 다시 연결합니다.
- 터미널에서 실행한 경우 `Ctrl+C`로 카메라와 트레이를 정리한 뒤 안전하게 종료할 수 있습니다.
